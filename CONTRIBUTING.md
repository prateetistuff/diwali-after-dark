# Contributing to Diwali After Dark

First of all, thank you for your interest in contributing to **Diwali After Dark!**

This project began as a collaborative experiment during OpenAI Student Collective's Studio Session 2, where participants came together to brainstorm, build, and play a multiplayer murder mystery game using ChatGPT.

We're opening the project to the community so everyone can continue experimenting, learning, and building together.

## How Can You Contribute?

Everyone is welcome to contribute, regardless of experience!

You can help by:

- **New Features:** Introduce new mysteries, character roles, clues, game modes, or interactive mechanics.
- **UI/UX Improvements:** Improve animations, responsiveness, accessibility, and visual design.
- **Game Mechanics:** Enhance voting, player interactions, role assignments, and multiplayer functionality.
- **Bug Fixes:** Identify and resolve issues affecting gameplay.
- **Documentation:** Improve instructions, explain features, or help new contributors understand the code.

Have another idea? We'd love to hear it!

## Getting Started

### 1. Fork the Repository

Click the **Fork** button at the top-right corner of this repository to create your own copy.

### 2. Clone Your Fork

Open a terminal and run:

`git clone https://github.com/YOUR_USERNAME/diwali-after-dark.git`

Then navigate into the project:

`cd diwali-after-dark`

### 3. Install Dependencies

Install Node.js 24.x and run:

`npm ci`

Follow the instructions in `README.md` to configure the local database and development environment.

### 4. Create a New Branch

Create a branch for your feature or fix:

`git checkout -b feature/your-feature-name`

### 5. Make Your Changes

Experiment, implement your ideas, and test your changes locally.

Please ensure your changes don't unintentionally break existing gameplay or multiplayer functionality.

### 6. Commit and Push

`git add .`

`git commit -m "Add: description of your feature"`

`git push origin feature/your-feature-name`

### 7. Submit a Pull Request

Open your fork on GitHub and click **Compare & pull request**.

Briefly explain what you changed, why you changed it, and how you tested it. Include screenshots for visual changes when possible.

Once reviewed, your changes may be merged into the main project!

## Contribution Guidelines

- Be respectful and constructive when discussing ideas.
- Keep changes focused and explain them clearly.
- Test your code before submitting.
- Never upload API keys, credentials, or private player information.
- Use GitHub Issues to discuss major changes before implementing them.
- Give appropriate credit when incorporating someone else's work.

## Built Together, Improved Together

Diwali After Dark started as a live collaborative experiment, and we'd love to see how far the community can take it.

Whether you're contributing your first line of code or introducing an entirely new game mechanic, your ideas are welcome.

**Happy building, and may the best detective win!**
